### Profile picture maker FAQ
#### What is the best size for a profile picture?
Optimal profile picture sizes vary across platforms, here are sizes for popular platforms:
- Facebook: 180 x 180 (displayed as 170 x 170 on desktops, 128 x 128 on smartphones)
- Instagram: 320 x 320
- Twitter/X: 400 x 400
- LinkedIn: 400 x 400 (recommended 800 x 800 for better quality)
- Pinterest: 165 x 165 (recommended 800 x 800)
- TikTok: 200 x 200
- YouTube: 800 x 800 (displayed as 98 x 98)
- Snapchat: 320 x 320
- WhatsApp: 192 x 192 (displayed as 140 x 140)
- Reddit: 256 x 256
- Tumblr: 128 x 128 (recommended 512 x 512 for higher resolution)
You can find size presets for most of these platforms in Picsart for effortless resizing.
